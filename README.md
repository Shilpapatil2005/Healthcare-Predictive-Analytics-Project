# Healthcare Predictive Analytics System

A Machine Learning based healthcare prediction system developed using Python and Streamlit.

This project predicts whether a patient may have diabetes using healthcare data and Machine Learning algorithms.

---

# Features

- Diabetes Prediction System
- Machine Learning Algorithms
- Logistic Regression
- Random Forest Classifier
- Interactive Web Application
- Patient Data Input
- Accuracy Calculation
- Analytics Dashboard
- Graph Visualization
- Login Authentication System

---

# Installation

## Step 1: Clone Repository

```bash
git clone https://github.com/Shilpapatil2005/Healthcare-Predictive-Analytics-Project.git
```

## Step 2: Open Project Folder

```bash
cd Healthcare-Predictive-Analytics-Project
```

## Step 3: Install Required Libraries

```bash
pip install streamlit pandas numpy scikit-learn matplotlib
```

## Step 4: Run Project

```bash
streamlit run app.py
```
